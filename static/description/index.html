How it works

Three clear steps to go live

1

Configure credentials

Go to Drupal → Configuration and enter the Drupal URL, username, and password.

2

Enable sync on records

On Product or Customer form, tick Sync with Drupal then click sync button to push.

3

Let automation run

A background job runs every 4 hours. You can always override with manual bulk actions.

FAQ

Good to know before you install

What entities are synced?

Products and Customers can be pushed from Odoo to Drupal. Products and Orders can be pulled from Drupal into Odoo.

How often does the scheduled job run?

By default every 4 hours. You can change the interval in Scheduled Actions if needed.

Can I run a manual bulk import?

Yes. Use the provided server actions to run bulk operations when you need immediate updates.

Where do I manage credentials?

In Odoo under Drupal → Configuration.
